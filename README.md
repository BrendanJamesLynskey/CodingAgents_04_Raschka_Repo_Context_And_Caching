# CodingAgents 04 — Live Repo Context & Prompt-Cache Reuse

Companion deck for **Components 1 + 2** of Sebastian Raschka's *[Components of a Coding Agent](https://magazine.sebastianraschka.com/p/components-of-a-coding-agent)*. Covers the workspace summary that gives an agent its "stable facts", the prompt-prefix architecture that separates stable from changing content, and the Anthropic / OpenAI prompt cache that turns a multi-thousand-token prefix from a recurring tax into a near-zero recurring cost.

Includes an interactive prompt-shape walkthrough, a live cache-cost calculator, and concrete patterns (`CLAUDE.md`, deterministic prefix builders, secondary breakpoints) you can carry into your own harness.

**Live site:** https://brendanjameslynskey.github.io/CodingAgents_04_Raschka_Repo_Context_And_Caching/
